# KMUTNB Admission

ต้นแบบระบบรับสมัครนักศึกษาออนไลน์ ใช้ HTML และ CSS เท่านั้น

## หน้าทั้งหมด

- index.html หน้าหลัก
- login.html, register.html, forgot.html เข้าสู่ระบบ สร้างบัญชี ลืมรหัสผ่าน
- rounds.html เลือกรอบสมัคร
- apply.html, education.html, courses.html, documents.html, review.html ขั้นตอนการสมัคร 5 ขั้น
- payment.html ชำระค่าสมัคร
- summary.html สถานะการสมัคร
- results.html ตรวจสอบผลการคัดเลือก
- faculties.html หลักสูตรที่เปิดรับ
- schedule.html ปฏิทินการรับสมัคร
- announcements.html ประกาศ
- faq.html, contact.html ช่วยเหลือและติดต่อ
- profile.html บัญชีของฉัน
- 404.html ไม่พบหน้า
